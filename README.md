# Gestor de tareas

CRUD de tareas hecho con HTML, CSS y JavaScript puro (sin backend). Los datos se guardan en el `localStorage` del navegador.

## Funcionalidades
- Crear, editar, completar y eliminar tareas
- Búsqueda con contador de resultados
- Filtros: Todas / Pendientes / Completadas
- Barra de progreso de tareas completadas

## Metodología de trabajo
Proyecto desarrollado con **Git Flow**:
- Ramas `main`, `dev` y `qa`
- 5 ramas de trabajo:
- `feature/setup-ui-bitacora`
- `feature/create-read-tasks`
- `feature/update-delete-tasks`
- `feature/search-and-filters`
- `hotfix/fix-date-format`
- Cada rama se integró mediante Pull Requests hacia `dev`, `qa` y `main`
